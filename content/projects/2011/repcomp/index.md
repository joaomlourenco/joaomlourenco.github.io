description: "This project aims at investigating how the multiple processing units in emerging multicore platforms can be used to improve the performance and reliability of applications. The idea is to use these cores to run replicated components that use alternate implementations (algorithms, data structures, etc.). Performance will be improved by using the best implementation for a particular operation, while reliability will be improved by using the redundancy available."
