  title: "Best Photo Selection"

  other: "This work addresses the issue of how to help the amateur photographer to select the best photo from a set of similar photos by analysing them in technical terms. The result is a novel workflow supported by a software package, guided by user input, which will allow the sorting of the similar photos accordingly to their technical characteristics (illumination and focus) and the user requirements."
